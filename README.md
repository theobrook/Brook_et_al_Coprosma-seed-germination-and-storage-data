The following repository contains the data for **Brook _et al._ (2026) "Germination behaviour and desiccation tolerance of _Coprosma_ (Rubiaceae) seeds from a remote oceanic island"**:

1. **non-parametric_data** - directory containing data used for the non-parametric analyses (i.e., radicle and shoot emergence percentages and timing), for _C. huttoniana_ (huttoniana.csv), _C. lanceolaris_ (lanceolaris.csv), and _C. ptotopetra_ (ptotopetra.csv)

2. **survival_data** - directorty containing data used for the survial analyses (i.e., germination across time at the individual seed level), for _C. huttoniana_ (huttoniana.csv), _C. lanceolaris_ (lanceolaris.csv), and _C. ptotopetra_ (ptotopetra.csv)

3. **imbibition_data.csv** - results from the imbibition trial for all three species testes (_C. huttoniana_, _C. lanceolaris_, and _C. ptotopetra_)
